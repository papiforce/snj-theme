# snj-theme

Thème AwesomeBB du forum **Sengoku no Jidai**. Voir `CLAUDE.md` pour les décisions et les règles,
et `docs/liaison-annexe.md` pour la liaison avec l'annexe.

## Installer le socle sur un forum

1. **CSS principal** : coller `src/css/critical.css` dans PA › Affichage › Couleurs › CSS principal.
2. **Template `overall_header`** : coller `src/templates/head-snippet.html` juste avant `</head>`,
   enregistrer puis valider le template.
3. **JavaScript** : créer un code « Sur toutes les pages » avec `src/js/theme-toggle.js`.
