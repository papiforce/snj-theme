# Skill « forumactif-awesomebb » — fichiers de référence

Version réécrite (nov. 2026) des fichiers `references/` du skill, à partir de ce qui a été vérifié sur le forum de
test Alendria pendant la refonte de Sengoku no Jidai. Ils restent génériques (valables pour tout forum AwesomeBB) :
les décisions propres à SnJ sont dans `CLAUDE.md`.

- `references/variables.md` — `_userdata` (clés réelles), variables de template, données lisibles dans les pages
- `references/javascript.md` — gestion des JS, règles de base, lecture d'autres pages, sélecteurs, patrons, PA
- `references/css-avance.md` — emplacements du CSS, feuille versionnée, variables `--t_*`, pièges, groupes, recettes
